Allow System Tray icons to be manually reordered from the Entries configuration page using drag-and-drop.

The custom order is saved and applied to the System Tray. A "Restore default order" action is also provided to return to the automatic ordering.


Depends on frameworks/kirigami!2156 (merged)

From the discussion so far, I think we have a few main options:

Remove categories completely.
Keep categories only for the default order, then switch to a custom order after reordering.
Keep categories as labels without actual grouping.
Keep real groups and allow reordering inside them.
Make the groups themselves configurable.
My preferred option would be to keep categories by default. Entries could be reordered freely inside a category, and the categories themselves could also be reordered.

If an entry is moved between categories, the grouping could disappear and the list would become fully custom. The tricky part is making that transition feel understandable.

Another option would be to make it explicit with a button at the top that switches between grouped and simple/custom ordering instead of changing automatically.
